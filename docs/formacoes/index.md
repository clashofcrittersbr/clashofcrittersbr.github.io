# Formações por fase

## Capítulo 18

O Critter Formations reúne formações para as fases **18-1 a 18-80**. Use o número da fase para localizar a composição. Cada registro mostra quem publicou, as posições, os Tiers e o nível informado na origem.

[Consultar capítulo 18 no Critter Formations](https://critterformations.com/chapter/18/)

## Como adaptar uma formação

1. Compare o nível e os Tiers do registro com os da sua equipe.
2. Reproduza as posições que você consegue. Se precisar trocar um Tatari, comece por uma unidade que cumpra a mesma função.
3. Observe onde o teste falhou ou o que mudou na vitória. Alterar uma coisa por vez ajuda a comparar as tentativas.

O capítulo 18 acima é uma referência externa. Os registros próprios serão adicionados conforme os editores publicarem resultados testados. [Veja o modelo de contribuição](../colabore.md#modelo-de-formacao).
